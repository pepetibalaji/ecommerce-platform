# Platform Documentation

This directory contains the current, source-aligned documentation for the platform.

1. [Functional requirements](functional-requirements.md) — what the platform does today and what remains.
2. [Non-functional requirements](non-functional-requirements.md) — security, reliability, operations, and quality rules.
3. [High-level design](high-level-design.md) — architecture, service boundaries, data ownership, and workflows.
4. [Low-level design](low-level-design.md) — event contracts, persistence, retries, security, and local operation.
5. [Frontend requirements](frontend-requirements.md) — customer, seller, and administrator web experience plus API boundaries.
6. [Frontend integration contract](frontend-integration.md) — Gateway-only browser integration and deployment prerequisites.
7. [Stage deployment plan](stage-deployment-plan.md) — portfolio-stage infrastructure, security, and release checks.

Each runnable service has its own README in its service directory. Those files explain the current implementation, dependencies, configuration, testing, and remaining work.
