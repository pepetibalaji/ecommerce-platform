# Current Implementation

Product Service owns the MongoDB `products` catalog document: UUID ID, seller UUID, name, description, Decimal128 price, category, brand, HTTPS image URLs, active flag, and timestamps. Public endpoints are `GET /api/v1/products` (pagination/category/price filters) and `GET /api/v1/products/{id}`. Admin routes create, bulk-create, update, and delete products; admin creation requires the target `sellerId`. Seller routes create/list/update/delete under `/api/v1/seller/products`; ownership is enforced in `ProductService` from JWT `userId`, while admins have platform-wide access. Newly created products publish `product-created` with product and seller IDs; failures increment `product_created_event_publish_failures_total`. The active flag is the catalog availability control used by Order Service. Dependencies: MongoDB, Kafka, OAuth/JWK, Config Server, Actuator, tracing, and Prometheus.
